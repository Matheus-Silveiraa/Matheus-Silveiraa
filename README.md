## 🚀 Projetos

### 🌻 [Sunflower](https://github.com/Matheus-Silveiraa/Sunflower)
Sistema web de apoio a pessoas com TDAH, desenvolvido como TCC do curso técnico. Fui responsável pela liderança técnica, pela arquitetura do banco de dados e pelo backend em PHP, com APIs REST, autenticação e geração de relatórios.
`PHP` `MySQL` `Python` `JavaScript` `JSON`

### 🌊 [Project Atlântida](https://github.com/Matheus-Silveiraa/Project-Atlantida) *(em desenvolvimento)*
Automação em Node.js e Puppeteer que faz login na plataforma FIAP EAD e coleta materiais e progresso de leitura, salvando os dados em JSON. Arquitetura modular, com planos para coleta de tarefas e provas e um bot do Discord para consulta.
`Node.js` `Puppeteer` `JSON`

### 🛰️ [NEXUS NETRA](https://github.com/Matheus-Silveiraa/NEXUS-NETRA) *(em desenvolvimento)*
Ferramenta de diagnóstico de rede que busca apontar possíveis causas de falha com base em evidências dos testes. Já executa ping com medição de latência e perda de pacotes sobre dispositivos cadastrados em JSON. Próximas etapas: dashboard web, testes de gateway e portas TCP, diagnóstico por regras e relatórios.
`Python` `ICMP` `JSON`

### 🧊 TecFreeze *(ferramenta interna, código privado)*
Automação em Python que gerencia o Unified Write Filter (UWF) em laboratórios Windows: identifica a máquina por IP e hostname, executa comandos administrativos e tem interface CLI. Uso no dia a dia. O código é privado por ser uma ferramenta de administração de ambiente real.
`Python` `subprocess` `CLI`
